# Client Forge

A modern multi-tenant SaaS platform for organizations, agencies, and enterprises to manage client relationships, operations, internal audits, finances, projects, and documents with grounded AI.

## ?? Quick Start (Frontend)

### 1. Enter the frontend directory
```bash
cd frontend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the Client Forge platform.

### 4. Build for production
```bash
npm run build
npm run start
```
